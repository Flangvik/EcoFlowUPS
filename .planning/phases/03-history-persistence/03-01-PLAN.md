  <action>
    Create `History/SqliteHistoryStore.cs`. Implement `IHistoryStore`.

    **Constructor:** Accept `string dbPath` and `ILogger<SqliteHistoryStore> logger`. Build the write connection string as `$"Data Source={dbPath};Mode=ReadWriteCreate"`. Read connection string as `$"Data Source={dbPath};Mode=ReadOnly"`. Do NOT open connections in the constructor.

    **`StartAsync(CancellationToken ct)`:** Open the write connection, call `ConfigureConnectionAsync`, create both tables and indexes (see schema below), then start `ConsumeWritesAsync(ct)` via `Task.Run`.

    **`ConfigureConnectionAsync(SqliteConnection conn)` — private static helper:**
    ```csharp
    private static async Task ConfigureConnectionAsync(SqliteConnection conn)
    {
        await conn.OpenAsync().ConfigureAwait(false);
        using var cmd = conn.CreateCommand();
        cmd.CommandText = "PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA busy_timeout=3000;";
        await cmd.ExecuteNonQueryAsync().ConfigureAwait(false);
    }
    ```
    Call this on EVERY connection open — write connection in StartAsync, and each read connection opened in QueryAsync.

    **Schema (DDL to run in StartAsync):**
    ```sql
    CREATE TABLE IF NOT EXISTS telemetry_snapshots (
        id          INTEGER PRIMARY KEY,
        device_sn   TEXT    NOT NULL,
        ts          INTEGER NOT NULL,
        battery_pct REAL,
        total_in_w  INTEGER,
        total_out_w INTEGER,
        power_state TEXT,
        remain_min  INTEGER,
        temp_c      REAL,
        source      TEXT
    );
    CREATE UNIQUE INDEX IF NOT EXISTS idx_telemetry_device_ts
        ON telemetry_snapshots (device_sn, ts DESC);

    CREATE TABLE IF NOT EXISTS power_events (
        id          INTEGER PRIMARY KEY,
        device_sn   TEXT    NOT NULL,
        ts          INTEGER NOT NULL,
        event_type  TEXT    NOT NULL,
        detail      TEXT,
        source      TEXT
    );
    CREATE INDEX IF NOT EXISTS idx_events_device_ts
        ON power_events (device_sn, ts DESC);
    ```

    **Channel field:**
    ```csharp
    private readonly Channel<TelemetrySnapshot> _writeQueue =
        Channel.CreateBounded<TelemetrySnapshot>(new BoundedChannelOptions(500)
        {
            FullMode = BoundedChannelFullMode.DropOldest,
            SingleWriter = false,
            SingleReader = true
        });
    ```

    **`EnqueueSnapshot(TelemetrySnapshot snapshot)`:** Call `_writeQueue.Writer.TryWrite(snapshot)`. If it returns false, log a warning (queue full, DropOldest handles it automatically).

    **`ConsumeWritesAsync(CancellationToken ct)` — private:**
    Drain the channel in batches. Wait up to 10 seconds for items. When items arrive, flush all available at once:
    ```csharp
    private async Task ConsumeWritesAsync(CancellationToken ct)
    {
        var batch = new List<TelemetrySnapshot>(50);
        while (!ct.IsCancellationRequested)
        {
            try
            {
                if (!await _writeQueue.Reader.WaitToReadAsync(ct).ConfigureAwait(false))
                    break;
                while (_writeQueue.Reader.TryRead(out var snap))
                    batch.Add(snap);
                if (batch.Count > 0)
                {
                    await FlushBatchAsync(batch, ct).ConfigureAwait(false);
                    batch.Clear();
                }
            }
            catch (OperationCanceledException) { break; }
            catch (Exception ex) { _logger.LogError(ex, "History write consumer error"); }
        }
    }
    ```

    **`FlushBatchAsync(List<TelemetrySnapshot> batch, CancellationToken ct)` — private:**
    Use the persisted write connection (never open a new one per flush). Use a `SqliteTransaction` for the entire batch. Use `INSERT OR IGNORE INTO telemetry_snapshots` (the unique index prevents duplicate ts per device):
    ```sql
    INSERT OR IGNORE INTO telemetry_snapshots
        (device_sn, ts, battery_pct, total_in_w, total_out_w, power_state, remain_min, temp_c, source)
    VALUES (@sn, @ts, @batt, @in, @out, @ps, @rm, @tc, @src)
    ```
    Wrap the loop in the same transaction and commit once at the end.

    **`QueryAsync(string deviceSn, DateTimeOffset from, DateTimeOffset to, Resolution resolution, CancellationToken ct)`:**
    Open a new `SqliteConnection` with the read connection string, call `ConfigureConnectionAsync` on it. Choose SQL based on resolution:
    - `Raw`: `SELECT * FROM telemetry_snapshots WHERE device_sn=@sn AND ts>=@from AND ts<=@to ORDER BY ts LIMIT 500`
    - `Hourly`: `SELECT strftime('%Y-%m-%d %H:00', ts, 'unixepoch') AS bucket, AVG(battery_pct), MAX(total_in_w), MAX(total_out_w), AVG(temp_c) FROM telemetry_snapshots WHERE device_sn=@sn AND ts>=@from AND ts<=@to GROUP BY bucket ORDER BY bucket`
    - `Daily`: same as Hourly but `strftime('%Y-%m-%d', ...)`
    - `Weekly`: same but `strftime('%Y-W%W', ...)`

    For aggregated resolutions, map result rows into `TelemetrySnapshot` records with `DeviceSn=deviceSn`, `Ts=0` (use bucket string), `BatteryPct=(float?)AVG`, `TotalInW=(int?)MAX`, `TotalOutW=(int?)MAX`, `TempC=(float?)AVG`, all other fields null, `Source="Aggregate"`.

    **`PruneAsync(TimeSpan retentionPeriod, CancellationToken ct)`:**
    ```sql
    DELETE FROM telemetry_snapshots WHERE ts < @cutoff
    ```
    `@cutoff = DateTimeOffset.UtcNow.Subtract(retentionPeriod).ToUnixTimeSeconds()`

    **`DisposeAsync()`:** Complete the writer (`_writeQueue.Writer.Complete()`), await the consumer task, dispose write connection.
