       DI will resolve them automatically since both are registered as singletons in `App.axaml.cs`.

    2. In `OnStateChanged(MonitorEntry entry, StateChangedEventArgs e)`, add the following block AFTER the existing `TriggerEvaluator` loop and BEFORE the `DeviceUpdated?.Invoke` call:

       ```csharp
       // -- History persistence (DATA-01) --
       var source = entry.Monitor is BleMonitor ? "BLE" : "Cloud";
       var snapshot = new TelemetrySnapshot(
           DeviceSn: entry.Device.SerialNumber ?? "",
           Ts:       DateTimeOffset.UtcNow.ToUnixTimeSeconds(),
           BatteryPct: e.State.Bms?.BatteryPct,
           TotalInW:   e.State.Display?.TotalInW,
           TotalOutW:  e.State.Display?.TotalOutW,
           PowerState: e.State.Power.Status.ToString(),
           RemainMin:  e.State.Bms?.RemainMin,
           TempC:      e.State.Bms?.TempC,
           Source:     source);
       _historyStore.EnqueueSnapshot(snapshot);

       // -- Event log (DATA-03): only on power state transitions --
       if (e.PreviousPower != e.State.Power.Status)
       {
           var eventType = DeriveEventType(e.PreviousPower, e.State.Power.Status);
           if (eventType != null)
           {
               var detail = $"Battery {e.State.Bms?.BatteryPct:F0}%";
               _eventStore.EnqueueEvent(new PowerEvent(
                   DeviceSn:  entry.Device.SerialNumber ?? "",
                   Ts:        DateTimeOffset.UtcNow.ToUnixTimeSeconds(),
                   EventType: eventType,
                   Detail:    detail,
                   Source:    source));
           }
       }
       ```

    3. Add the private helper method to `MonitorOrchestrator`:
       ```csharp
       private static string? DeriveEventType(PowerStatus previous, PowerStatus current) =>
           (previous, current) switch
           {
               (PowerStatus.OnBattery, PowerStatus.Charging) => "PowerRestored",
               (PowerStatus.Charging, PowerStatus.OnBattery) => "PowerLost",
               (PowerStatus.Connected, PowerStatus.OnBattery) => "PowerLost",
               _ => null
           };
       ```
       Return `null` for transitions we don't record (e.g. `Unknown -> Connected`).

    4. Note: the local `source` variable is already computed in the original `OnStateChanged` method at the bottom (`var source = entry.Monitor is BleMonitor ? "BLE" : "Cloud";`). Remove the duplicate — hoist it to before the TriggerEvaluator block and use it for both the DeviceUpdated raise and the history write.

    5. Add `using EcoFlowMonitor.History;` to the top of `MonitorOrchestrator.cs` if not already present.
