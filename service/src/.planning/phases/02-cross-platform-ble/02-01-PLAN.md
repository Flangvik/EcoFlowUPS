    void StopScan();

}

Class `WinRtBleAdapter : IBleAdapter`:

Fields:
- `private BluetoothLEAdvertisementWatcher? _watcher;`
- `private readonly Dictionary<ulong, BluetoothLEAdvertisementReceivedEventArgs> _advertisementCache = new();`

`event EventHandler<BleAdvertisement>? AdvertisementReceived;`

`StartScanAsync(CancellationToken ct = default)`:
1. Clear `_advertisementCache` at the start of every call (prevents stale entries across scan sessions).
2. Create a new `BluetoothLEAdvertisementWatcher { ScanningMode = BluetoothLEScanningMode.Active }`.
3. Subscribe `_watcher.Received += OnAdvertisementReceived`.
4. Call `_watcher.Start()`.
5. `try { await Task.Delay(Timeout.Infinite, ct); } catch (OperationCanceledException) { }` — BleMonitor cancels after 8 seconds; OperationCanceledException is expected.
6. `finally { StopScan(); }` — always clean up.

`StopScan()`:
1. Check `_watcher?.Status == BluetoothLEAdvertisementWatcherStatus.Started` before stopping.
2. **CRITICAL:** `_watcher.Received -= OnAdvertisementReceived` BEFORE `_watcher.Stop()` — prevents event delivery after stop.
3. Call `_watcher.Stop()`.

`OnAdvertisementReceived(BluetoothLEAdvertisementWatcher sender, BluetoothLEAdvertisementReceivedEventArgs args)` (private):
1. Cache: `_advertisementCache[args.BluetoothAddress] = args;`
2. Extract manufacturer data:
   ```csharp
   ushort mfgId = 0;
   byte[]? mfgData = null;
   if (args.Advertisement.ManufacturerData.Count > 0)
   {
       var section = args.Advertisement.ManufacturerData[0];
       mfgId = section.CompanyId;
       var reader = Windows.Storage.Streams.DataReader.FromBuffer(section.Data);
       mfgData = new byte[reader.UnconsumedBufferLength];
       reader.ReadBytes(mfgData);
   }
   ```
3. Raise `AdvertisementReceived?.Invoke(this, new BleAdvertisement { DeviceId = args.BluetoothAddress.ToString(), Name = args.Advertisement.LocalName ?? "", Rssi = args.RawSignalStrengthInDBm, ManufacturerId = mfgId, ManufacturerData = mfgData });`
   Note: `DeviceId` is `ulong.ToString()` (decimal string). This MUST match what `WinRtGattConnection.ConnectAsync` expects.

`CreateConnection()`:
- Return `new WinRtGattConnection(_advertisementCache);`
  The connection receives the cache so it can look up the `BluetoothAddress` ulong from the decimal-string `DeviceId`.

Class `WinRtGattConnection : IBleGattConnection`:

Constructor: `WinRtGattConnection(Dictionary<ulong, Windows.Devices.Bluetooth.Advertisement.BluetoothLEAdvertisementReceivedEventArgs> advertisementCache)` — stores as `_advertisementCache` field.

Fields:
- `private readonly Dictionary<ulong, ...> _advertisementCache;`
- `private BluetoothLEDevice? _device;`
- `private IReadOnlyList<GattDeviceService>? _services;`
- `private GattCharacteristic? _subscribedCharacteristic;`
- `private EventHandler<GattValueChangedEventArgs>? _valueChangedHandler;`
- `public bool IsConnected { get; private set; }`
- `public event EventHandler<byte[]>? NotificationReceived;`

**`ConnectAsync(string deviceId, CancellationToken ct = default)`:**
1. Parse address: `ulong address = ulong.Parse(deviceId);` — DeviceId is stored as `ulong.ToString()` in WinRtBleAdapter.
2. `_device = await BluetoothLEDevice.FromBluetoothAddressAsync(address);`
3. If `_device == null`: throw `InvalidOperationException($"Device {deviceId} not found in WinRT cache. A scan must precede every connect attempt.")` — this happens if no prior scan populated the OS advertisement cache.
4. Subscribe: `_device.ConnectionStatusChanged += OnConnectionStatusChanged;`
5. **CRITICAL — force real OS connection:** `var servicesResult = await _device.GetGattServicesAsync(BluetoothCacheMode.Uncached);`
   Using `BluetoothCacheMode.Uncached` is mandatory. `Cached` returns stale OS data and can produce `Unreachable` failures after device power cycle.
6. If `servicesResult.Status != GattCommunicationStatus.Success`: throw `InvalidOperationException($"GATT service discovery failed: {servicesResult.Status}")`.
7. `_services = servicesResult.Services;` — hold strong reference; disposing disconnects.
8. `IsConnected = true;`

**`OnConnectionStatusChanged(BluetoothLEDevice sender, object args)` (private):**
- If `sender.ConnectionStatus == BluetoothConnectionStatus.Disconnected`: `IsConnected = false;`

**`SubscribeNotifyAsync(Guid serviceUuid, Guid characteristicUuid, CancellationToken ct = default)`:**
1. Find service: `var svc = _services?.FirstOrDefault(s => s.Uuid == serviceUuid) ?? throw new InvalidOperationException($"Service {serviceUuid} not found");`
2. Discover characteristics (Uncached): `var charsResult = await svc.GetCharacteristicsForUuidAsync(characteristicUuid, BluetoothCacheMode.Uncached);`
3. If `charsResult.Status != GattCommunicationStatus.Success`: throw.
4. `var ch = charsResult.Characteristics.FirstOrDefault() ?? throw new InvalidOperationException($"Characteristic {characteristicUuid} not found");`
5. **CRITICAL — prevent handler accumulation on reconnect:**
   ```csharp
   if (_valueChangedHandler != null)
       _subscribedCharacteristic!.ValueChanged -= _valueChangedHandler;
   ```
6. Create and store handler:
   ```csharp
   _valueChangedHandler = (_, args) =>
   {
       var reader = DataReader.FromBuffer(args.CharacteristicValue);
       byte[] data = new byte[reader.UnconsumedBufferLength];
       reader.ReadBytes(data);
       NotificationReceived?.Invoke(this, data);
   };
   _subscribedCharacteristic = ch;
   ch.ValueChanged += _valueChangedHandler;
   ```
7. Enable notifications: `await ch.WriteClientCharacteristicConfigurationDescriptorAsync(GattClientCharacteristicConfigurationDescriptorValue.Notify);`

**`WriteAsync(Guid serviceUuid, Guid characteristicUuid, byte[] data, CancellationToken ct = default)`:**
1. Find service and characteristic using same pattern as SubscribeNotifyAsync (Uncached).
2. Write:
   ```csharp
   var writer = new DataWriter();
   writer.WriteBytes(data);
   var status = await ch.WriteValueAsync(writer.DetachBuffer(), GattWriteOption.WriteWithResponse);
   if (status != GattCommunicationStatus.Success)
       throw new InvalidOperationException($"GATT write failed: {status}");
   ```

**`DisconnectAsync()`:**
1. Unsubscribe ValueChanged first:
   ```csharp
   if (_valueChangedHandler != null && _subscribedCharacteristic != null)
       _subscribedCharacteristic.ValueChanged -= _valueChangedHandler;
   _valueChangedHandler = null;
   _subscribedCharacteristic = null;
   ```
2. Unsubscribe ConnectionStatusChanged: `if (_device != null) _device.ConnectionStatusChanged -= OnConnectionStatusChanged;`
3. Dispose all held service references (disposing releases OS GATT connection):
   ```csharp
   if (_services != null)
       foreach (var svc in _services) svc.Dispose();
   _services = null;
   ```
4. `_device?.Dispose(); _device = null;`
5. `IsConnected = false;`

**`DisposeAsync()`** (from IAsyncDisposable):
- Call `await DisconnectAsync();` and return `ValueTask.CompletedTask`.
