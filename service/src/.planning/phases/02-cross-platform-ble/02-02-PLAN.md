**Step 2 — Implement BlueZPermissionCheck.cs:**

Namespace: `EcoFlowMonitor.Platform.Linux`

```csharp
namespace EcoFlowMonitor.Platform.Linux;

public static class BlueZPermissionCheck
{
    public static void EnsureBluetoothGroupMembership()
    {
        // Only run this check on Linux; on other OS (e.g. macOS build machine) skip.
        if (!OperatingSystem.IsLinux()) return;

        try
        {
            var psi = new System.Diagnostics.ProcessStartInfo("id", "-nG")
            {
                RedirectStandardOutput = true,
                UseShellExecute = false,
                CreateNoWindow = true
            };
            using var proc = System.Diagnostics.Process.Start(psi)
                ?? throw new InvalidOperationException("Could not start 'id' process");
            var output = proc.StandardOutput.ReadToEnd();
            proc.WaitForExit();

            var groups = output.Split(new[] { ' ', '\n', '\r' },
                StringSplitOptions.RemoveEmptyEntries);

            if (!groups.Contains("bluetooth"))
            {
                throw new InvalidOperationException(
                    "BLE on Linux requires membership in the 'bluetooth' group.\n" +
                    "Fix: sudo usermod -aG bluetooth $USER\n" +
                    "Then log out and log back in, or run: newgrp bluetooth");
            }
        }
        catch (InvalidOperationException)
        {
            throw; // re-throw our own descriptive errors
        }
        catch (Exception ex)
        {
            // If 'id' binary is missing or unreadable, log and continue rather than block startup.
            // The D-Bus call will fail with a descriptive error if permissions truly are wrong.
            System.Diagnostics.Debug.WriteLine($"[BlueZPermissionCheck] Could not verify bluetooth group: {ex.Message}");
        }
    }
}
```

`StartScanAsync(CancellationToken ct = default)`:
1. **Preflight check:** `BlueZPermissionCheck.EnsureBluetoothGroupMembership();` — MUST be first, before any BlueZ call.
2. Clear cache: `_deviceCache.Clear();`
3. Get adapter:
   ```csharp
   _adapter = await BlueZManager.GetAdapterAsync("/org/bluez/hci0")
       ?? (await BlueZManager.GetAdaptersAsync()).FirstOrDefault()
       ?? throw new InvalidOperationException("No Bluetooth adapter found. Ensure bluetooth service is running.");
   ```
4. Create and store the handler:
   ```csharp
   _deviceFoundHandler = async (IAdapter1 a, DeviceFoundEventArgs e) =>
   {
       try
       {
           var props = await e.Device.GetAllAsync();
           var address = props.Address;
           if (string.IsNullOrEmpty(address)) return;

           _deviceCache[address] = e.Device;

           ushort mfgId = 0;
           byte[]? mfgData = null;
           // ManufacturerData is IDictionary<ushort, byte[]> in Linux.Bluetooth 5.67.1
           if (props.ManufacturerData != null && props.ManufacturerData.Count > 0)
           {
               var first = props.ManufacturerData.First();
               mfgId = first.Key;
               mfgData = first.Value;
           }

           AdvertisementReceived?.Invoke(this, new BleAdvertisement
           {
               DeviceId = address,          // "AA:BB:CC:DD:EE:FF" — matches ConnectAsync expectation
               Name = props.Name ?? "",
               Rssi = props.RSSI,
               ManufacturerId = mfgId,
               ManufacturerData = mfgData
           });
       }
       catch { /* swallow per-device parse errors to keep scan running */ }
   };
   _adapter.DeviceFound += _deviceFoundHandler;
   ```
5. `await _adapter.StartDiscoveryAsync();`
6. `try { await Task.Delay(Timeout.Infinite, ct); } catch (OperationCanceledException) { }` — BleMonitor cancels after 8 seconds.
7. `finally { await StopScanAsync(); }` — always clean up.

`StopScan()`:
- Synchronous wrapper. Call `StopScanAsync().GetAwaiter().GetResult()` with a guard to avoid deadlocks in synchronous context:
  Actually implement as:
  ```csharp
  public void StopScan() => _ = StopScanAsync();
  private async Task StopScanAsync()
  {
      if (_adapter == null) return;
      if (_deviceFoundHandler != null)
      {
          _adapter.DeviceFound -= _deviceFoundHandler;
          _deviceFoundHandler = null;
      }
      try { await _adapter.StopDiscoveryAsync(); } catch { /* ignore if not scanning */ }
  }
  ```
  Note: IBleAdapter.StopScan() is void. BleMonitor calls it after awaiting StartScanAsync, so the fire-and-forget pattern is safe here since StartScanAsync already calls StopScanAsync in its finally block before returning. The void StopScan() is a redundant safety call.

`CreateConnection()`:
- `return new BlueZGattConnection(_deviceCache);`

   `await _device.WaitForPropertyValueAsync("ServicesResolved", value: true, TimeSpan.FromSeconds(15));`
   If this is skipped, `GetServiceAsync` returns null immediately after `ConnectAsync` returns.

**`SubscribeNotifyAsync(Guid serviceUuid, Guid characteristicUuid, CancellationToken ct = default)`:**

   ```csharp
   ch.Value += _notifyHandler;
   ```
5. `await ch.StartNotifyAsync();`

**`WriteAsync(Guid serviceUuid, Guid characteristicUuid, byte[] data, CancellationToken ct = default)`:**
